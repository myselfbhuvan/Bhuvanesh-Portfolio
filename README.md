# Bhuvanesh K — Portfolio

A modern responsive portfolio for Bhuvanesh K, focused on Cloud, DevOps, software development and hands-on projects.

## Run locally

No build tools are required.

1. Open `index.html` in a browser.
2. For a local server, use VS Code Live Server or any static web server.


This portfolio is intentionally suitable for the CI/CD project:

GitHub → Jenkins → Docker → GHCR → Terraform → AWS/EC2 → Docker → Website
